# HadaraLab

برنامج **مفتوح المصدر** تابع إلى **كلية الحضارة الجامعة**، **قسم هندسة تقنيات الحاسوب**.
وهو بيئة برمجية مصغّرة تعتمد صيغة لغة الماتلاب، وقد صُمِّم لمادة **أسس هندسة السيطرة** (Control Engineering Fundamentals) في المرحلة الثالثة.

- **برمجة وإعداد:** محمد عبدالرحمن محمود
- **الموقع الإلكتروني:** https://mohmadev.com/
- **البريد الإلكتروني للدعم:** support@mohmadev.com
- **الرخصة:** رخصة MIT للمصادر المفتوحة، ونصّها الكامل في الملف `LICENSE`.
- **الخصوصية:** لا يجمع البرنامج أي بيانات ولا يتصل بالإنترنت. التفاصيل في الملف `PRIVACY.md`.

> **إشعار:** اسم كلية الحضارة الجامعة ملكٌ للكلية، ويُستخدم في هذا البرنامج لأغراض هذا المشروع البرمجي فقط.
> ولا تشمله رخصة MIT، ولا يجوز استخدامه خارج هذا المشروع إلا بإذن مسبق من الكلية.

## طريقة التشغيل

- **النسخة الجاهزة:** شغِّل الملف `dist\HadaraLab\HadaraLab.exe`، ولا يحتاج إلى أي تثبيت مسبق.
- **من الشيفرة المصدرية:**
  ```
  pip install -r requirements.txt
  python main.py
  ```
  أو انقر نقراً مزدوجاً على الملف `run.bat`.

## مكونات البرنامج

| المكوِّن | الوصف |
|---|---|
| **المحرك (Engine)** | محلِّل معجمي (Lexer) ومحلِّل نحوي (Parser) ومفسِّر (Interpreter) مكتوبة خصيصاً لهذا المشروع. يدعم المتغيرات والمصفوفات وجمل `if` و`for` و`while` و`switch`، والدوال `function` و`@(x)`، والفهرسة مثل `A(2,:)` و`end`. |
| **محرر الشيفرة** | تلوين الشيفرة، وترقيم الأسطر، والإكمال التلقائي (Tab)، وتحويل الأسطر إلى تعليقات بالاختصار `Ctrl+/`، وتمييز السطر الذي يحتوي على الخطأ. |
| **نافذة الأوامر** | تنفيذ الأوامر مباشرةً مع سجلّ للأوامر السابقة (السهمان ↑ و↓). |
| **مساحة العمل (Workspace)** | عرض المتغيرات وقيمها وأنواعها. |
| **الرسوم البيانية** | التكبير والتحريك والحفظ بصيغة PNG، وعرض قيم النقطة عند النقر على المنحني. وعلى المحل الهندسي للجذور تُعرض قيم K وζ وωn. |
| **أداة ضبط متحكم PID** | ضبط المعاملات Kp وKi وKd بمنزلقات مع تحديث فوري للاستجابة ومواصفاتها، مع زر للضبط التلقائي وزر لطريقة زيغلر-نيكولز (الفصل العاشر من كتاب Ogata). |
| **التوافق مع كتاب Ogata** | يقبل الصيغة القديمة المستخدمة في الكتاب مثل `step(num,den,t)` و`[y,x,t] = step(...)` و`rlocus(num,den)` و`bode(A,B,C,D)`. |
| **جدول راوث** | جدول راوث ملوَّن يعالج الحالات الخاصة (الصفر في العمود الأول، والصف الصفري بالكامل)، ويحدِّد مدى الكسب K اللازم للاستقرار. |
| **المخطط الصندوقي** | رسم المخطط الصندوقي (التوالي والتوازي والتغذية العكسية) وحساب دالة التحويل الكلية. |
| **المظهر** | مظهر فاتح ومظهر داكن، ويُختار من قائمة Settings ثم Theme، ويُطبَّق بعد إعادة تشغيل البرنامج. |

## دوال السيطرة المتاحة

`tf`, `zpk`, `ss`, `pid`, `series`, `parallel`, `feedback`, `minreal`, `pole`, `zero`, `dcgain`,
`step`, `impulse`, `ramp`, `lsim`, `stepinfo`, `stepspecs`, `ess`, `damp`,
`routh`, `krange`, `rlocus`, `rlocinfo`, `sgrid`, `pzmap`,
`bode`, `margin`, `nyquist`, `bandwidth`, `ss2tf`, `tf2ss`, `tf2zp`, `zp2tf`, `ode45`,
`initial`, `rlocfind`, `zntune`, `acker`, `place`, `lqr`, `ctrb`, `obsv`, `ord2`, `printsys` ...

ودوال الرسم: `plot`, `mesh`, `surf`, `polar`, `gtext`, `subplot` ...

إضافةً إلى أكثر من 150 دالة رياضية ودوال للمصفوفات والرسم. اكتب الأمر `help` داخل البرنامج لعرض القائمة الكاملة.

## مثال

```matlab
G = tf(10, [1 3 2]);      % دالة التحويل
T = feedback(G, 1);       % نظام الحلقة المغلقة
step(G, T); grid on       % الاستجابة لدالة الخطوة
S = stepinfo(T)           % مواصفات الاستجابة
routh([1 3 2 10])         % جدول راوث
rlocus(G); sgrid          % المحل الهندسي للجذور
margin(G)                 % هامش الكسب وهامش الطور
```

## الأمثلة

يحتوي المجلد `examples` على 14 مثالاً مرتبة وفق مفردات المادة: الأساسيات، وأنظمة الحلقة المفتوحة والمغلقة،
ودالة التحويل ومحرك التيار المستمر، والمخططات الصندوقية، والاستجابة الزمنية، والمتحكمات PID، ومعيار راوث،
والمحل الهندسي للجذور، ومخطط بود، والمخطط القطبي ومعيار نايكوست، وتصميم المعوِّضات Lead وLag وLag-Lead، وفضاء الحالة.

ويحتوي المجلد `examples/ogata` على 16 برنامجاً من كتاب **Ogata, Modern Control Engineering** (الطبعة الرابعة)
مكتوبة بصيغة الكتاب نفسها، ونتائجها مطابقة لما ورد فيه. فعلى سبيل المثال يعطي البرنامج Program 5-6 القيم:
rise time = 0.5550 وpeak time = 0.7850 وovershoot = 0.0948 وsettling time = 1.1850.

ملاحظة: لا تظهر هذه الأمثلة في واجهة البرنامج، ويمكن فتحها من قائمة File ثم Open.
